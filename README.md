# StudentManagementSystem
A Java console-based Student Information System implementing CRUD operations, OOP principles, input validation, and formatted output using ArrayList.
Student Information System
📌 Project Overview

The Student Information System is a Java console-based application designed to manage student records efficiently.

It allows users to:

Add new students

View all student records

Search students by ID or name

Update student details

Delete student records

The system follows Object-Oriented Programming (OOP) principles and uses ArrayList for dynamic data storage. It also includes input validation and formatted output to ensure reliability and readability.

🎯 Objectives

Implement core Java concepts

Practice CRUD operations (Create, Read, Update, Delete)

Apply encapsulation and modular design

Validate user input with error handling

Build a structured, resume-ready Java project

🛠 Technologies Used

Java (JDK 8 or higher)

OOP Concepts (Classes, Objects, Encapsulation)

ArrayList

Scanner Class

Exception Handling

Java JDK 8 or above installed
